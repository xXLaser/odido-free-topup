# Odido Free Top-up

Automatisch den **gratis** 2 GB Fair-Use-Aanvuller von Odido Unlimited nachladen.

**→ Ausführliche Anleitung für Einsteiger:** [`ANLEITUNG.md`](ANLEITUNG.md)

Kurz:

1. Doppelklick **`einrichten.bat`**
2. Token + Handynummer in `.env` eintragen (siehe Anleitung)
3. **`testen.bat`** → dann **`starten.bat`**

Geprüft: Sept. 2026 — Fair Use 20 GB/Tag + gratis `A0DAY01` weiterhin aktuell.
